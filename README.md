# Game Net CMS

A comprehensive management system for internet cafes (game nets) that runs locally on Windows PCs. Built with pure HTML, CSS, and JavaScript for maximum compatibility and ease of deployment.

## Features

- **💰 Price Calculator**: Automatic calculation of session costs based on time usage
- **📊 Revenue Reports**: Detailed income tracking and financial reporting
- **👥 User Management**: Complete customer account and session management
- **⏱️ Time Tracking**: Real-time monitoring of active sessions and time management
- **💻 Offline Operation**: Fully functional without internet connection
- **🖥️ Windows Compatible**: Optimized for Windows PC environments
- **📦 Static Application**: No server or database installation required

## Installation

1. Download the latest release
2. Extract the files to your desired location
3. Open `index.html` in your web browser
4. Start managing your game net!

## Usage

### Starting a Session
1. Select or device for play
2. Click "Start Session"
3. The timer begins automatically

### Ending a Session
1. Select the active session
2. Click "End Session"
3. View calculated cost and payment details

### Generating Reports
1. Navigate to Reports section
2. Select date range
3. View revenue, session statistics, and customer data

## Technical Details

- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **Storage**: LocalStorage API
- **Platform**: Windows (cross-browser compatible)
- **Requirements**: Modern web browser (Chrome, Firefox, Edge)
