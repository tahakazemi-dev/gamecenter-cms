# سیستم مدیریت گیم نت

یک سیستم جامع برای مدیریت گیم نت‌ها که به صورت کاملاً آفلاین روی ویندوز اجرا می‌شود. با استفاده از HTML، CSS و JavaScript خالص ساخته شده تا نصب و استفاده از آن بسیار آسان باشد.

## ویژگی‌ها

- **💰 محاسبه قیمت**: محاسبه خودکار هزینه بر اساس زمان استفاده
- **📊 گزارش‌گیری درآمد**: ثبت دقیق درآمد و گزارش‌های مالی تفصیلی
- **👥 مدیریت کاربران**: مدیریت کامل حساب مشتریان و سشن‌ها
- **⏱️ مدیریت زمان**: نظارت لحظه‌ای بر سشن‌های فعال و کنترل زمان
- **💻 عملکرد آفلاین**: کار کردن کامل بدون نیاز به اینترنت
- **🖥️ سازگار با ویندوز**: بهینه‌سازی شده برای محیط ویندوز
- **📦 برنامه استاتیک**: بدون نیاز به نصب سرور یا دیتابیس

## نصب و راه‌اندازی

1. آخرین نسخه را دانلود کنید
2. فایل‌ها را در مسیر دلخواه Extract کنید
3. فایل `index.html` را با مرورگر باز کنید
4. شروع به مدیریت گیم نت کنید!

## نحوه استفاده

### شروع یک سشن
1. پروفایل مشتری را انتخاب یا ایجاد کنید
2. روی "شروع سشن" کلیک کنید
3. تایمر به صورت خودکار شروع می‌شود

### پایان یک سشن
1. سشن فعال را انتخاب کنید
2. روی "پایان سشن" کلیک کنید
3. هزینه محاسبه شده و جزئیات پرداخت را مشاهده کنید

### تهیه گزارش
1. به بخش گزارش‌ها بروید
2. بازه زمانی را انتخاب کنید
3. درآمد، آمار سشن‌ها و اطلاعات مشتریان را مشاهده کنید

## جزئیات فنی

- **Frontend**: HTML5, CSS3, JavaScript خالص
- **ذخیره‌سازی**: LocalStorage API
- **پلتفرم**: ویندوز (سازگار با تمام مرورگرها)
- **نیازمندی‌ها**: مرورگر مدرن (Chrome, Firefox, Edge)
